## 3. v1 からの改善点（すべて `config.yaml` に事前登録）

1. 目的変数を LM（5・10・20日の相対リターン順位の平均）にし、N に依存しないモデルにした
2. N=5/10/20 の Sharpe の平均（台地の高さ）で選定する
3. LightGBM は5シードのアンサンブル
4. グリッドを 96 通りに削減（v1 は 6,912 通り）
5. レジームフィルタ（SMA200 より下かつ低ボラの日は買わない）
6. 待機資金を 1321 で保有し、G3 ゲートに B2（1321 の買い持ち）との比較を追加
7. 単純モデルの比較対象として M2r（短期リバーサルの固定合成）を追加

## 4. 結果

### Step 5: 特徴量の評価（2016-09〜2020-08、目的変数 LM）
- 63 候補のうち、**採用は r_upper_sh（上ヒゲの長さ）の1つだけ**でした（t_NW = 2.24、年別符号一致率 80%）。
- **v1（2005〜2009年）で一貫して有意だった短期リバーサルは、この期間では有意ではありません。** 連騰日数・前日リターン・EMA5 乖離・連落日数の t 値は -0.7〜-0.9 でした。
- そのため M2b・M4r・M5 の銘柄固有の特徴量は1つだけになりました。LightGBM の内側検証 IC は、回帰 0.0003、lambdarank 0.0065 です。

### 解釈
- 2020〜2025年は、無作為選択でもモデルでも、N を長くするほど Sharpe が上がりました。**成績の大部分は市場全体の上昇（ベータ）によるもので、銘柄選択の効果ではありません。**
- どのモデルも無作為選択を上回りませんでした。LightGBM（M4r・M5）は単純な合成（M2r・M2b）より良くならず、1取引あたりの期待値はほぼ0でした。
- θ（10% と 20%）の結果は同一でした。K=3〜5 では上位数銘柄が必ず θ の内側に入るため、θ が実質的に効いていません（設計上の問題）。
